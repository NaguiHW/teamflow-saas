# TeamFlow SaaS — MVP Product Description

## Target user

TeamFlow is for small and medium-sized product, operations, and client-service teams that need one shared place to coordinate work. The primary user is a team lead or organization owner who creates the workspace and needs visibility into project progress. Team members use it to manage assigned work; viewers need read-only visibility.

## Problem

Team work is often fragmented across chat, spreadsheets, and disconnected task lists. Teams lose context about ownership, due dates, decisions, and recent activity. TeamFlow provides a focused, organization-scoped workflow for turning projects into visible, accountable tasks.

## Product promise

A team can create an organization, organize work into projects, assign and discuss tasks, and understand recent operational activity without needing a complex enterprise tool.

## Primary flow

1. A user registers or signs in.
2. The user creates an organization and becomes its `owner`.
3. The owner invites teammates.
4. An authorized member creates a project.
5. The team creates tasks, assigns them, adds labels, due dates, and comments.
6. Members track project progress and review organization activity.

## MVP success criteria

- A new user can reach a useful organization workspace without administrator assistance.
- An owner can invite another user and manage membership access.
- A team can complete the project-and-task flow end to end.
- A user from one organization cannot read or mutate another organization’s data.
- Important changes are visible in an audit trail.
